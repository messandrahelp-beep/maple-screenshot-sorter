메이플 스샷 정리 사용법

1. "메이플 스샷 정리.exe" 를 더블클릭해요.
2. 처음 한 번은 설정 창이 떠요. 폴더 3개를 확인하고 "저장"을 눌러요.
   - 게임 스샷 저장 위치: 게임 설정에서 고른 곳 (기본 C:\Nexon\Maple)
   - 자동 촬영 옮길 폴더: 파일 이름이 Maple_A_ 로 시작하는 스샷
   - 직접 촬영 옮길 폴더: 파일 이름이 Maple_숫자 로 시작하는 스샷
3. 그 뒤로는 작업 표시줄 오른쪽(시계 옆) 아이콘으로 계속 돌아가요.
   새 스샷이 생기면 윈도우가 알려줘서 그때만 옮겨요. (혹시 몰라 1분마다 한 번 더 확인)

키로 메이플 창 찍기 (1.1.0 버전부터)
- 메이플 창이 맨 앞에 있을 때 Pause 키를 누르면 게임 화면만 찍어서 "직접 촬영" 폴더에 저장해요.
- 파일 이름은 messandra_261118_133341.png 꼴이에요. 앞부분(messandra)은 설정 창에서 바꿀 수 있어요.
- 창 모드나 테두리 없는 전체화면에서만 돼요. 전체화면 모드에서는 게임 안 스크린샷을 써 주세요.
- 키는 Pause, Scroll Lock, Print Screen 중에서 고를 수 있어요. 찍을 때 소리는 끌 수 있어요.
- 이 기능을 켜면 프로그램이 관리자 권한으로 켜져요. 메이플이 관리자 권한으로 돌아서,
  그래야 메이플 안에서 누른 키가 들어와요. 켤 때 뜨는 허용 창에서 "예"를 눌러 주세요.
- 폴더 칸 옆 "열기"를 누르면 그 폴더가 열려요.

아이콘 오른쪽 클릭 메뉴
- 설정 열기 / 지금 정리하기 / 폴더 열기 / 끝내기
- 창의 X 를 눌러도 꺼지지 않아요. 끄려면 "끝내기".

그 밖에
- "컴퓨터 켤 때 자동으로 켜기"를 체크하고 저장하면 다음부터 알아서 켜져요.
- "달마다 폴더 나누기"를 체크하면 2026-11 같은 폴더로 나눠요.
- 같은 이름 파일이 있으면 지우지 않고 "(2)"를 붙여요.
- 무엇을 옮겼는지는 "옮긴 기록.txt"에 남아요.
- 설정은 exe 옆 settings.json 에 저장돼요. exe를 다른 폴더로 옮길 때는 같이 옮기고,
  자동 켜기를 쓰고 있었다면 한 번 껐다 다시 켜고 저장해 주세요.
- 처음 켤 때 윈도우가 "PC 보호" 창을 띄우면 "추가 정보 → 실행"을 누르면 돼요.
  (직접 만든 프로그램이라 서명이 없어서 그래요)

다시 만들기 (코드를 고쳤을 때)
- 소스 폴더의 만들기.ps1 을 실행하면 exe가 새로 만들어져요.
