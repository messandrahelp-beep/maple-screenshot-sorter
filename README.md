# 메이플 스샷 정리

메이플스토리 스크린샷을 **자동 촬영**과 **직접 찍은 것**으로 나눠서, 내가 정한 폴더로 자동으로 옮겨 주는 작은 윈도우 프로그램이에요. 키 하나로 **메이플 창만** 찍을 수도 있어요.

게임 설정에서는 스크린샷 저장 위치를 메이플스토리 폴더, 바탕화면, `C:\` 중에서만 고를 수 있어요. 이 프로그램을 켜 두면 새로 찍힌 스샷을 원하는 곳으로 바로 옮겨 줘요.

## 받기

**[최신 버전 받기](https://github.com/messandrahelp-beep/maple-screenshot-sorter/releases/latest)** 에서 `MapleShotSorter-버전.zip` 을 받아 압축을 풀고 `메이플 스샷 정리.exe` 를 실행하면 돼요. 설치는 필요 없어요.

- 윈도우 10 / 11
- 사양 낮은 컴퓨터에서도 가벼워요: 받는 파일 18KB, 메모리 약 35MB, 쉬는 동안 CPU 0%

소개 페이지: https://messandra.com/maple-shot-sorter/

## 쓰는 법

1. `메이플 스샷 정리.exe` 실행 → 설정 창이 떠요
2. 폴더 3개를 확인하고 **저장**
   - 게임 스샷 저장 위치 (기본 `C:\Nexon\Maple`)
   - 자동 촬영 옮길 폴더 (`Maple_A_...` 파일)
   - 직접 촬영 옮길 폴더 (`Maple_...` 파일)
3. 창을 닫아도 시계 옆 아이콘으로 계속 돌아가요. 오른쪽 클릭 메뉴에서 설정 열기, 지금 정리하기, 폴더 열기, 끝내기를 할 수 있어요.

## 키로 메이플 창 찍기 (1.1.0부터)

- 메이플 창이 맨 앞에 있을 때 **Pause** 키를 누르면 게임 화면만(제목줄 빼고) 찍어서 직접 촬영 폴더에 저장해요.
- 파일 이름은 `messandra_261118_133341.png` 꼴이에요. 앞부분은 설정 창에서 바꿀 수 있어요.
- 키는 Pause · Scroll Lock · Print Screen 중에서 고를 수 있어요. 찍으면 짧은 "띡!" 소리가 나고(끌 수 있어요), 찍지 못하면 윈도우 알림음("띵")이 나요.
- **창 모드나 테두리 없는 전체화면**에서만 돼요. 전체화면 모드에서는 게임 안 스크린샷을 써 주세요.
- 윈도우 캡처 도구의 "창 찍기"와 같은 방식이에요. 화면에 보이는 메이플 창 부분을 그대로 복사할 뿐, 게임에 키를 보내거나 게임을 건드리지 않아요.

**왜 관리자 권한이 필요한가요?**
메이플은 관리자 권한으로 돌아요. 윈도우는 관리자 권한이 없는 프로그램이 관리자 권한 창 앞에서 키를 받지 못하게 막아서, 이 기능을 켜면 프로그램도 관리자 권한으로 켜져요. 켤 때 뜨는 허용 창에서 **예**를 누르면 돼요. 기능을 끄면 관리자 권한을 요청하지 않아요.

## 선택 기능

- 컴퓨터 켤 때 자동으로 켜기 (창 없이 아이콘으로만 켜져요)
  - 키로 찍기를 켰으면 작업 스케줄러에, 아니면 시작 프로그램 목록에 올려요. 관리자 권한 프로그램은 시작 프로그램 목록으로는 켜지지 않아서 그래요.
- 달마다 폴더 나누기 (예: `2026-11`)
- 같은 이름 파일이 있으면 지우지 않고 `(2)` 를 붙여요
- 폴더 칸 옆 **열기** 버튼
- 옮기고 찍은 내역은 exe 옆 `옮긴 기록.txt` 에 남아요

## 자주 묻는 것

**"Windows의 PC 보호" 창이 떠요.**
코드 서명 인증서가 없는 개인 프로그램이라 처음에 뜰 수 있어요. **추가 정보 → 실행** 을 누르면 돼요.

**게임에 문제가 생기지 않나요?**
게임 프로그램과 게임 파일에는 손대지 않아요. 인터넷 연결도 하지 않아요.

**어떤 파일을 옮기나요?**
이름이 `Maple_숫자...` 또는 `Maple_A_숫자...` 인 그림 파일(png, jpg, bmp)만 옮겨요. 다른 파일은 건드리지 않고, 지우지도 않아요.

**설정은 어디에 저장되나요?**
exe 옆 `settings.json` 에 저장돼요.

**지우려면?**
자동으로 켜기를 썼다면 먼저 체크를 풀고 저장해요. 그다음 아이콘 오른쪽 클릭 → 끝내기, 폴더를 지우면 끝이에요.

## 직접 만들기

코드는 [`소스/MapleShotSorter.cs`](소스/MapleShotSorter.cs) 파일 하나예요. 윈도우에 기본으로 들어 있는 C# 컴파일러로 만들 수 있어요.

```
powershell -ExecutionPolicy Bypass -File 소스\만들기.ps1
```
